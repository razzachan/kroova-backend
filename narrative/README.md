## 📖 Como Usar Esta Documentação

### Para Escritores/Roteiristas:
- Leia `KROUVA_UNIVERSE.md` primeiro (fundação)
- Consulte `KROUVA_CHARACTERS.md` para perfis
- Use `KROUVA_BOOK_OUTLINE.md` como guia

### Para Designers de Cartas:
- Leia `KROUVA_UNIVERSE.md` (tom e facções)
- Use `KROUVA_CARD_LORE_SYSTEM.md` como template
- Consulte `KROUVA_FACTIONS_DEEP_DIVE.md` para contexto

### Para Marketing:
- Leia `KROUVA_UNIVERSE.md` (pilares)
- Use `KROUVA_MARKETING_NARRATIVO.md` para campanhas
- Consulte `KROUVA_TIMELINE.md` para eventos

### Para Produção de Vídeo:
- Leia `KROUVA_VEO3_SCRIPTS.md` (roteiros prontos)
- Consulte `KROUVA_BRANDING.md` (na raiz) para estética
- Use `KROUVA_CHARACTERS.md` para design de personagens

## 🎬 Princípios Narrativos de Krouva

1. **Sátira Inteligente:** Crítica social afiada, nunca panfletária
2. **Cyberpunk Orgânico:** Tech + humanidade, não só chrome frio
3. **Transmídia Coerente:** Todos os meios contam a mesma história
4. **Comunidade Co-cria:** Torneios e eventos afetam o cânone
5. **Cartas São Personagens:** Cada uma tem história, não só stats
